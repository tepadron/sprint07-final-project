# sprint07-final-project
El objetivo de este proyecto es realizar un análisis exploratorio de datos para identificar patrones de comportamiento, características demográficas y hábitos de consumo de los usuarios.
A través de la limpieza, transformación y análisis de los datos, se busca identificar segmentos de clientes según su edad y nivel de uso de los servicios, con la finalidad de generar información útil para la toma de decisiones y el desarrollo de estrategias comerciales.
Para el desarrollo del proyecto se utilizaron los siguientes conjuntos de datos:
  plans: contiene información de qué incluyen los paquetes Básico y Premium
  users: contiene información general de los usuarios, como identificador, nombre, apellido, edad, ciudad, fecha de registro, plan contratado y fecha de cancelación.
  usage: contiene información relacionada con el comportamiento de uso de los servicios, incluyendo cantidad de mensajes, llamadas y minutos consumidos.
    Se realizó exploración de datos, limpieza y preparación, análisis y visualización, segmentación de datos y finalmente la intepretación de datos
